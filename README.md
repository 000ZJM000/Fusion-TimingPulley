# 同步带轮草图生成器（Fusion）

作者：Jeremy · 发布日期：2026年10月30日 · 发行版：v0.8.0（V2）

用于 Autodesk Fusion 的同步带轮二维闭合齿廓草图生成插件。支持 HTD 名义尺寸参考模型与 GT 2/3/5 mm 理论共轭轮槽。

## 支持范围

| 系列 | 型号 | 生成依据与限制 |
| --- | --- | --- |
| GT | 2GT、3GT、5GT | 原厂独立带齿尺寸 + 滚动共轭包络；理论无加工间隙轮槽 |
| HTD | 2M、3M、5M、8M、14M、20M | 保留历史名义尺寸与相切约束模型，不声明完整 ISO 齿廓符合性 |
| HTD 自定义 | 自定义节距 | 按 5M 参考尺寸缩放，属于非标自定义几何 |

GT 的 2/3/5 表示毫米节距；GT2、GT3 等是产品代际，不能由名称推断为同一槽形。当前未把 ISO G8M/G14M 或大节距 GT 按比例缩小成小节距 GT。

## GT 数据与方法

原厂资料：[Gates Unitta GT 目录](https://www.unitta.co.jp/data/support/pdf/cat-b02-14/cat-b01-20_P014_087.pdf)，印刷页 46、50、54；方法来源：[Gates US4515577A 专利](https://patents.google.com/patent/US4515577A/en)。

以下均为原厂**带齿**尺寸，单位 mm；不是把带齿的圆弧直接当成轮槽圆弧。

| 型号 | 节距 p | 根部圆角 R1 | 齿侧圆弧 R2 | 齿顶圆弧 R3 | 齿间平顶宽 b | 带齿高 h | 节线差 PLD |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 2GT | 2 | 0.15 | 1.00 | 0.555 | 0.40 | 0.75 | 0.254 |
| 3GT | 3 | 0.25 | 1.52 | 0.850 | 0.61 | 1.14 | 0.381 |
| 5GT | 5 | 0.51 | 2.54 | 1.370 | 1.03 | 1.93 | 0.5715 |

- 节圆直径 `Dp = p × z / π`，外圆直径 `Do = Dp − 2 × PLD`。
- 先按原厂圆弧尺寸和相切条件构造带齿，再让带齿的节线相对节圆作无滑动滚动，求其扫掠的轮槽包络。
- 随齿数重新求共轭曲线；不缩放另一节距的齿形，不用任意圆弧替代齿侧。
- 输出包含受容差控制的曲线离散。结果记录离散容差、计算方法与资料来源。
- 当前模型无加工间隙，未包含原厂制造公差、材料变形、安装张力或动态补偿；这不是原厂制造轮槽认证。

GT 模式固定节距和带齿参数。界面齿数范围 12–400 为软件范围，不是负载能力或推荐最小带轮直径。无法形成有效齿顶或轮廓的输入会被拒绝。

具体共轭公式（`Rot` 表示二维旋转）：设带齿边界为 `(x(a), d(a))`，`d` 从带齿根面向轮心为正，`R = pz/(2π)`、`u = PLD`，则

```text
Q(a,t) = Rot(t) · (x(a) + R·t, R − u − d(a))
det(∂Q/∂a, ∂Q/∂t) = 0
t = [−(u+d)·d′/x′ − x] / R
```

当源边界为圆弧 `(cx+r cos a, cd+r sin a)` 时，滚动角解析化为 `t = [(u+cd) cot a − cx] / R`。程序修剪隐藏的折返分支，按每个真实光滑分支的共轭坐标和解析端点切线构造三次 NURBS。分支内部仅使用单重节点，保持一阶、二阶导数连续；保留真实分支交界和槽底端点。

样条误差通过 `|理论曲线−样条| ≤ |理论曲线−弦| + |样条−弦|` 控制。第一项由二阶导数界 `M·Δa²/8` 控制，第二项用三次 Bezier 控制多边形给出界限；自动模式按需细分以满足默认 0.001 mm 上限。固定点数模式保留输入点数并报告所得界限。另使用极角导数的 Bernstein 符号界防止插值产生折返或相邻齿槽重叠。公式及实现见 `lib/tpg/gt.py` 和 `lib/tpg/spline.py`，无需 SciPy 等运行时依赖。

在 12–400 齿扫描中，2GT 全部通过，3GT 的 12/13 齿、5GT 的 12–17 齿因当前理论模型产生欠切/悬垂分支而拒绝。这些是求解器适用边界，不能解读为原厂产品不存在这些齿数。

## 使用

从 [GitHub Releases](https://github.com/000ZJM000/Fusion-TimingPulley/releases) 下载 `TimingPulleyGenerator-v0.8.0.zip`，解压得到 `TimingPulleyGenerator` 文件夹。

1. 将该文件夹复制到 Fusion 插件目录：`%APPDATA%\Autodesk\Autodesk Fusion 360\API\AddIns\`；或在“脚本和附加模块”中添加解压后的 `TimingPulleyGenerator` 目录。
2. 打开 Fusion → 实用工具 → 脚本和附加模块（Shift+S）→ 附加模块 → 运行。
3. 插件按钮位于“实体 → 创建”和“草图 → 创建”面板。
4. 已有安装应先停止插件再覆盖文件，随后重新运行；入口和核心库均显示 v0.8.0。

不要把 `.py`、`.manifest` 与 `lib`、`resources` 拆开放置。ZIP 的顶层插件文件夹名称已与入口文件保持一致。

1. 选择齿形系列、型号和齿数。
2. 可选放置平面/已有草图及圆心点；未指定时使用当前草图或 XY 平面原点。
3. 在结果页核对尺寸和模型范围，再生成草图。
4. 默认保留同名草图并递增命名；勾选覆盖时，新轮廓生成成功后才删除旧草图。

添加到已有草图时只固定新生成的曲线。构造圆、槽宽线、中心线及文字标注均可选。

## 可调采样与连续曲线（v0.8.0）

在“齿槽几何”页选择 **GT 采样方式**：

| 方式 | 可调项 | 行为 |
| --- | --- | --- |
| 按误差自动采样（默认） | GT 曲线误差上限，默认 0.001 mm | 自动分配点数，保持所选误差上限 |
| 指定每齿采样点数 | 9–513 的奇数，初值 33 | 每个完整齿槽含两端和槽底；保留各包络分支连接点，结果报告所得误差上界 |

点数越少越快、误差越大；固定点数模式不会暗中增加点数来满足另一项误差设置。两种模式都从同一共轭公式计算采样坐标。

“输出选项”的 **GT 连续光滑曲线（推荐）** 默认开启：每个真实光滑分支写成一条 C2 三次 NURBS，齿顶保持精确圆弧。内部采样点用于插值精度，不再成为折角，因此不会按采样点分割拉伸侧壁。分支交界仍可能有少量真实接缝。

连续曲线内部采用单重节点，消除采样折角导致的密集拉伸分面。以 2GT、20 齿为例，使用 120 条光滑分支曲线和 20 段外圆弧，而非 1540 段采样折线。增加插值点不会为每个采样点增加独立草图曲线。

固定样条不能直接拖动控制点编辑。关闭推荐选项时才输出旧式折线。连续曲线写入失败会撤销本次生成，保留原草图，不自动退回折线。更新插件后请用新版重新生成草图并重新拉伸，已有旧实体不会仅因更新插件而改变。

写入已有草图时，按 [Autodesk 的延后计算要求](https://help.autodesk.com/cloudhelp/ENU/Fusion-360-API/files/fusion_Sketch_isComputeDeferred.htm)先回退时间线到草图后方，批量写入后恢复计算和原时间线位置；无法安全回退时保留普通计算方式。新增曲线不再逐段触发已有草图的重算。完成弹窗显示实际生成秒数，文本命令日志另记录写入、重算、轮廓识别各阶段耗时。
