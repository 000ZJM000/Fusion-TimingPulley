# 同步带轮草图生成器（Fusion 360 插件）

> **作者**：Jeremy  
> **发布日期**：2026年9月19日  
> **版本**：v0.5.0

按机械行业标准与国际标准（ISO 13050 / JB/T 7512.2）自动生成同步带轮轮齿轮廓**草图**的 Autodesk Fusion 360 插件。
全部几何参数精准可调，几何求解引擎与 Fusion API 完全解耦（纯 Python 闭式解析计算），支持全功能离线自检与真机环境自愈。

---

## 一、支持型号

本插件完整支持以下标准 HTD 高扭矩圆弧齿规格及任意自定义节距：
- **HTD 2M**（节距 2.0 mm）
- **HTD 3M**（节距 3.0 mm）
- **HTD 5M**（节距 5.0 mm）
- **HTD 8M**（节距 8.0 mm）
- **HTD 14M**（节距 14.0 mm）
- **HTD 20M**（节距 20.0 mm）
- **自定义节距 HTD**（取消“节距自动”后可输入任意合法节距，如 $p = 7.5\text{ mm}$）

---

## 二、安装与启动

1. 把整个 `TimingPulleyGenerator` 目录复制到 Fusion 360 的插件目录：

   ```text
   %APPDATA%\Autodesk\Autodesk Fusion 360\API\AddIns\
   ```

   Windows 默认完整路径：
   `C:\Users\<用户名>\AppData\Roaming\Autodesk\Autodesk Fusion 360\API\AddIns\TimingPulleyGenerator\`

2. 打开 Fusion 360 → **实用工具（Utilities）** → **脚本和附加模块（Add-Ins）**（快捷键 `Shift + S`）；
3. 在 **附加模块（Add-Ins）** 页签中选中 `TimingPulleyGenerator`；
4. 点击 **运行（Run）**；建议同时勾选 **开机自动运行（Run on Startup）**；
5. 插件按钮将出现在 **实体 → 创建** 与 **草图 → 创建** 工具面板中，图标名为 **同步带轮**。

> **热重载支持**：更新插件代码时，无需重启 Fusion 360，只需在对话框中点击 **停止（Stop）** 再点击 **运行（Run）**，插件内置的模块刷新机制会自动生效。

## 三、参数界面详解

对话框按功能组织为 4 个页签，**所有能计算的标准尺寸实时自动解算，所有标准公称值均支持用户个性化覆盖**。

### 1. 基本参数

| 参数 | 默认 / 范围 | 说明 |
| :--- | :--- | :--- |
| **放置平面** | 可选（面 / 基准面 / 草图） | 未选择时默认自动绑定当前激活草图或零件 XY 构造面 |
| **圆心点** | 可选（草图点 / 顶点 / 圆心） | 指定轮心放置点；未选择时默认原点 (0, 0) |
| **齿形系列** | HTD（高扭矩圆弧齿） | 工业标准高扭矩圆弧齿形 |
| **型号** | 2M / 3M / 5M / 8M / 14M / 20M | 对应标准节距规格 |
| **节距自动** | 勾选（默认） | 取消勾选后可自由输入任意合法节距（如非标 $p = 7.5\text{ mm}$） |
| **齿数 z** | 常用范围（6 ~ 400） | 整数微调器；切换型号时自动适配最小/最大齿数 |

### 2. 齿槽几何

| 参数 | 默认推荐值 | 说明 |
| :--- | :--- | :--- |
| **槽底圆弧半径系数 `r_b/p`** | 3M: 0.3033 ($r_b = 0.91\text{ mm}$) | JB/T 7512.2 标准槽底半径比例；支持手动微调 |
| **齿槽齿形角 2β（参考值）** | ≈ 14.0° | **国标参考值**。齿形倾角由标称槽宽 $s$、槽深与圆弧严格相切解析自动导出，通常无需手动更改 |
| **单边间隙系数 `c/p`** | 0.00 | 加工配合余量；标准无额外单边间隙 |
| **外径收缩系数 `2δ/p`** | 3M: 0.254 ($2\delta = 0.762\text{ mm}$) | $D_{out} = D_{pitch} - 2\delta$。如需严格吻合国内常用表 $0.760\text{ mm}$，输入 `0.25333` |
| **槽深系数 `h/p`** | 0（自动） | 0 代表严格采用国标推荐公称槽深（如 3M 为 $1.28\text{ mm}$） |
| **齿顶倒角半径 `r_t`** | 3M: 0.30 mm | 保护同步带、防止齿顶锐边割伤皮带的标准圆角 |

### 3. 输出选项

- **草图名称**：支持自定义草图名。
- **覆盖同名草图**：勾选时覆盖删除旧草图；未勾选时自动递增重命名（如 `同步带轮 (1)`）。
- **构造线辅助图元**：
  - **绘制节圆（构造线）**：外径直径计算与传动速比核对基准；
  - **绘制齿根圆（构造线）**：槽底最低点所在圆周；
  - **绘制外圆（构造线）**：带轮顶圆基准；
  - **绘制齿槽标称宽构造线**：严格连接两端齿顶切点，精准等于标准槽口宽 $s$（如 3M 为 $1.90\text{ mm}$），便于在 CAD 中用尺寸工具快速验收；
  - **绘制齿槽对称中心线**：垂直穿过主齿槽底对称点与原点，便于建立重合与对称约束。
- **文字标注**：是否在草图上输出带轮直径与参数文字。
- **折线退避**：极端异常参数下无法闭合圆弧时自动降级为细分折线保护。

### 4. 结果与实时核算

实时显示节圆直径、外圆直径、齿根圆直径、标准槽深、槽口宽度、槽底圆弧半径、齿顶间隙校验与轮廓总段数。

## 四、几何引擎与标准符合性 (v0.5.0)

### 1. 标准单齿 7 段光滑相切拓扑 (G1 连续)

每个齿距严格由 7 段一阶连续光滑相切的几何图元首尾相接构成（无齿顶倒角时退化为 5 段）：
1. **右齿侧斜线**：从齿顶倒角切点平滑过渡到槽底圆弧切点；
2. **右槽底圆弧**：从右侧切点顺时针延伸至中央对称轴最低点 $(0, y_{bot})$；
3. **左槽底圆弧**：从中央最低点 $(0, y_{bot})$ 顺时针延伸至左侧切点；
4. **左齿侧斜线**：与左槽底圆弧光滑相切向上；
5. **左齿顶倒角弧**：严格内切于外圆与齿侧斜线；
6. **齿顶外圆弧**：沿外圆周连接至下一个齿槽；
7. **右齿顶倒角弧**：平滑接合下一齿槽右斜线。

> **槽底中心顶点**：根据工程制图标准，槽底在对称中心最低点 $(0, y_{bot})$ 拥有显式独立的草图顶点，可直接用于标注槽深尺寸（$h_g = 1.28\text{ mm}$）、原点共线约束及水平相切约束。

### 2. 标准齿形角 2β 的受驱动原理

在 JB/T 7512.2 标准中，齿形角标注为 **$2\beta \approx 14^\circ$**。
本插件采用解析几何算法，当槽宽 $s$、槽深 $h_g$、底弧 $r_b$、倒角 $r_t$ 确定后，斜线倾角 $\beta$ 被唯一几何确定（单侧约为 $6.87^\circ \sim 7.1^\circ$，双边约为 $13.7^\circ \sim 14.2^\circ$），实现全闭环零间隙、零台阶的严格相切。

```text
├── TimingPulleyGenerator.py        # 插件生命周期入口、命令注册与热重载

    ├── test_dryrun.py              # API 桩干跑测试
    └── fusion_stub.py              # 纯 Python Fusion API 仿真桩
```
